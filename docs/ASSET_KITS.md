# ClashAI free 2D asset kits

Scope: free only (name-your-price at $0 counts, logins and $0 checkouts are fine). Static character images are enough; we animate procedurally. Target: cartoon Clash-like look, ~30 troop roles, plus towers, buildings, VFX and UI.

Roster coverage counts are estimates against the 30 roles (knight, archers, giant, gunner, heavy knight, goblins, spear goblins, skeletons, baby dragon, hog rider, axe warrior, wizard, witch, imps, prince, balloon, bomber, golem, barbarians, bats, miner, mega knight, bandit, princess, ice wizard, lava beast, executioner, lumberjack, elemental spirits).

Preview URLs were checked with HTTP requests. Broken ones are dropped. See `asset-kits.html` for the visual cards.
